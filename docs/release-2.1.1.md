## Idle Legions 多开中控 v2.1.1

修掉上一版几个"点了没反应"的问题，锁帧补上全局档位，换了新图标。

### 修复

- **顶栏图标点不动**：事件委托白名单里没有 `data-sponsor` / `data-github` / `data-lock`，所以点「发布页」「赞助」「锁帧」都没反应。现在全部接上，赞助跳到爱发电（带 utm 链接）。
- **锁帧写了不生效**：锁帧写的是实例自己的 `settings.cfg`，而游戏只在启动时读 `max_fps`。现在写入后会问一句「重启这个实例让锁帧生效？」，确认后自动关游戏再拉起来，不需要手动折腾。

### 新增

- **全局锁帧**：顶栏新增 `锁帧 10 / 30 / 不锁`，一次写入所有实例；写入后同样可以一键重启全部实例让它生效。账号卡片上仍可单独设某一档。
- **顶栏「退出」**：和「全部开始 / 全部停止」同一排，点了就退出中控（右上角 X 仍然只是缩到任务栏）。

### 变更

- **新图标**：游戏风格（同色系：深海军蓝 + 金 + 银），但构图换成 2×2 的多开窗口格，避免和游戏本体图标混淆；exe、桌面 / 开始菜单快捷方式、侧栏图标一起换。
- 版本号 v2.1.1，页脚与检测更新同源。

### 下载

`IdleLegionsConsole-v2.1.1-win-x64.zip` 解压后双击 `Idle Legions 多开中控.exe`。
