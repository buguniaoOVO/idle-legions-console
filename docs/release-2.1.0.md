## Idle Legions 多开中控 v2.1.0

首个公开版本。把主机和各个 Sandboxie 沙箱里的 Idle Legions 客户端收进一个窗口。

### 本版内容

- **品牌化**：名称与图标统一为「Idle Legions 多开中控」，图标取自游戏 `client.exe` 的 PE 图标资源（16/24/32/48/64/128/256 全部原地替换）。
- **账号状态**：每实例一屏看全在线、自动、关卡、金币/时、背包、邮件与最近动作。
- **锁帧**：账号卡片上直接选 `10 / 30 / 不锁`，写该实例自己的 `settings.cfg`（重启实例生效）。
- **掉落记录**：整行按品质上色，品质与类别改为纯文字，不再套背景框。
- **沙箱**：Sandboxie 探测、逐箱部署助手、逐箱启停；端口在 8840–8843 扫描并随实例回报。
- **检测更新**：只比较版本号，界面不出现仓库地址；检查中 / 已是最新 / 有新版本 / 检测失败分开显示。
- **顶栏与页脚**：发布页、赞助两个图标；页脚常驻版本号与 `by AWan`。

### 下载

`IdleLegionsConsole-v2.1.0-win-x64.zip` 解压后双击 `Idle Legions 多开中控.exe`。

### 环境要求

- Windows 10 / 11 x64，Microsoft Edge WebView2 Runtime
- 沙箱多开需要 Sandboxie Plus（本工具不安装 Sandboxie 本体）

### 说明

非官方玩家工具，与游戏开发商及 X1X 无隶属关系；只做本机进程、窗口与文件层面的管理，不修改游戏内存。
